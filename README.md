# Inspo Canvas

Bootstrap av Moodboard app MVP (fase 0-1):

- Next.js App Router + TypeScript
- Lys minimalistisk base + glass UI tokens
- Enkel masonry canvas med mock data
- Item popup med metadata + vibe prompt

## Kom i gang

Krav: Node.js 20+ og npm 10+

```bash
npm install
npm run dev
```

Åpne deretter http://localhost:3000
